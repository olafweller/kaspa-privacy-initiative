| Obligation | Implemented enforcement | Evidence / remaining boundary |
|---|---|---|
| Economic domain | Circuit/commitments/NFs derive from explicit TN10 genesis + fixed lane + unfunded pool nonce. VK/native program are excluded from domain derivation. | New key/image pinned; old local artifacts preserved. No domain migration. |
| Public statement and valid/invalid decision | Same real wallet relation; shared canonical payload checks; checked Arkworks proof decoding + established accelerated Groth16 equation over all fourteen full-width field inputs. | Native differential and actual guest execution. No host validity flag. |
| Prior private state/config | Entire ledger + covenant hash into one SMT resource. Input preimage must match the journal's previous root. Native start/end lane commitments are derived from all v1 transaction preimages. | Guest substitution assertions pass. The final on-chain covenant must check that previous root/tip against its authenticated predecessor; no canonical TN10 predecessor was observed here. |
| Native deposit existence/value/script | Deposit descriptor identifies owner and output index. Derive native v1 ID from actual payload/rest; derive a unique deposit reference from ID/index. Read positive value, script version, exact P2SH(delegate_entry_script(committed covenant)) and unbound flag from that output. | Wrong/zero/missing/covenant-bound outputs reject. Acceptance is conditional on the native lane endpoint; a self-consistent locally invented transaction is not a real deposit. |
| Credit/refund single consumption | Later credit/recovery proof binds that already-known deposit reference/value/owner. Current pending record can be consumed once. | Avoids circularly binding a proof to the native ID that contains itself. Current-state races tested. Stable native recovery if a verifier/program becomes unusable remains an unfunded-trial gate. |
| Current nullifiers and notes | Previous state contains allowed historical roots and current NF set. Verify actual proof before atomic clone/commit; duplicate economic NF, root and capacity checks remain. | Distinct valid competing old-root proof rejects after an earlier accepted batch. |
| Ordering and rejection | Existing native v1 hashing, mergeset context, activity digest and lane-tip/seqcommit implementation includes every payload, accepted or rejected. Reference transaction journal decoder checks generated journals. | Four sequential fixture endpoints/states connect. Omission/reorder/substitution changes computed endpoint; an actual mismatched native settlement proof has not been produced/tested for this image. |
| Exit destination/principal | Wallet intent binds SHA256 of the canonical StandardSpk encoding. Envelope carries that exact P2PK destination; guest checks the binding and emits the same destination/value through the existing permission accumulator. | This hash is an app commitment, not a Kaspa P2SH hash. Wrong destination rejected; accumulator returns the actual permission-script hash. No arbitrary owner/admin exit shortcut. |
| Native aggregate ABI | Guest commits exactly 352 bytes in existing StateTransition order, with old/new roots/tips, seqcommit, covenant, permission/deposit hashes and lane key. | Monolithic transaction/batch slots use explicit relation-domain constants. Separate recursive transaction/batch image identities and proofs are not supplied by this calibration. No extra outer Groth16 conversion is assumed. |
| Actual payout and reserve debit | Pending exits remain liabilities. No fixture payout-confirmation call exists in the new guest path. | Need actual permission consumption, exact native output, single use and confirmed lineage before changing paid/reserve state. No native script verification/accepted payout has occurred. |
| Fees/rent and data recovery | Zero app fees; public parameter save/load and separate local Bob backup/discovery/proving demonstrated. | Native fees/rent/refunds, persistent independent public-data/parameter availability and second-machine recovery remain before funding. |

The replayable fixture inputs are public native preimages and public state only.
Private backup/parameters directories are never copied wholesale to evidence.
A setup artifact, a computed permission hash or a matching execution journal is
not a real Succinct receipt or native payout.
