# Historical one-attempt B operator sources

These finite scripts record the owner-authorized 2026-10-20 experiment. They are
retained for audit, not as commands for another rental. Allocation, start and
deletion intents are exclusive; uncertain responses require read-only
reconciliation rather than repeating a mutation. A future trial needs a fresh
identity and its own release.

The existing Cloud → TN10 → B route staged each source unchanged on B. Credentialed
provider/service operations ran in finite systemd processes with the existing
root-only B EnvironmentFile; account and service-token values never entered
Cloud, command lines, Git or downloaded evidence. CPU verification ran without
that EnvironmentFile and uses only the prequalified public package. B root is a
trusted operator, not a cryptographic boundary against an administrator.

The independently installed guard, not these finite management scripts, performs
runtime backup and deadline/terminal stop. Its exact unit and source bindings
are retained with the experiment evidence. No additional executor, Cloud secret,
Cloud domain or gateway runtime dependency was introduced.

`cloud_verify.py` records the finite Cloud-side CPU recheck; its local `.local`
paths describe this historical workspace. Use the top-level retained evidence
checker for reproduction from a clean checkout.
